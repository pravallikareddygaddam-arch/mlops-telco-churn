# Lab 7 – Churn Prediction MLOps Pipeline

## Objective
To implement an end-to-end MLOps pipeline for Telco Customer Churn Prediction.

## Pipeline Stages
1. Data Loading
2. Raw Data Validation
3. Data Preprocessing
4. Processed Output Validation
5. Model Training and MLflow Registry
6. Model Evaluation
7. Model Quality Gate
8. Automated Model Lifecycle
9. Batch Inference
10. Failure Injection and Handling

## Execution
The pipeline loads churn data, validates it, preprocesses the data, trains and evaluates the model, and manages the model lifecycle.

## Result
The MLOps pipeline stages were documented for customer churn prediction. Successful execution should be verified from the actual pipeline output.
