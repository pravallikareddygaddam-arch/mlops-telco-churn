# Lab 9 – Failure Handling Report

## Objective
To test failure detection and handling in the Churn Prediction MLOps pipeline.

## Procedure
1. Introduce corrupted data using failure injection.
2. Validate the input data.
3. Detect invalid data and validation errors.
4. Record failures in reports.
5. Verify that the pipeline handles failures appropriately.

## Result
The failure-handling report documents the testing procedure. Successful failure detection and handling must be verified from the actual pipeline output.
