# Task 3 – Spring MVC with Thymeleaf and Bootstrap

## Run
Run `mvn spring-boot:run`, then open `http://localhost:8083`. The page displays sample students and a form to add a student. The controller adds data to the Model; Thymeleaf renders the model dynamically. This is an in-memory demonstration, so records reset when the application restarts. Bootstrap CSS is loaded from its CDN (internet required for styling).
